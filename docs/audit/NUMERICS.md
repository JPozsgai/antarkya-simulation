# Complete numeric literal inventory

Every numeric literal in the ten active JavaScript runtime files is listed, including signs, nearest named unit, surrounding expression and exact source line. This is deliberately an exhaustive **literal** inventory: indices, hashes, canvas geometry and engineering thresholds are not all empirical parameters. Computed values and user-provided inputs are described in the technical rules and source, not invented as fixed literals. The source link gives the entire expression when a table context is abbreviated.
