# Evidence and source provenance

This separates accepted design authority from empirical inputs, theoretical inspiration and engineering assumptions. A theoretical source supports a mechanism choice, not the exact numerical coefficient assigned to it. Stored URLs/dates are reproduced as provenance; freshness is not inferred from the documentation date. Private supplied texts are not redistributed.

## Numerical evidence classes

| Class | Treatment in this model |
| --- | --- |
| Dated observation / descriptor | Stored value, year, unit, source and retrieval metadata; not converted directly into corruption prevalence. |
| Sourced proxy | Rescaled or incomplete indicator; both original meaning and mapping are disclosed. |
| Institutional fact / routing note | Simplified current national architecture; full procedure is not implied. |
| Unmeasured condition | Neutral scenario prior or null evidence, explicitly editable; missing is not evidence of zero. |
| Engineering prior | Explicit coefficient/cost/distribution chosen to make a bounded exploratory model; requires calibration/sensitivity checks. |
| User design decision | Governs intended mechanism; does not by itself establish empirical effect size. |
